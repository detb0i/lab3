Лабораторна робота №3. Функції в JavaScript

Натискайте кнопки, щоб запустити завдання. Результати — в alert та в журналі внизу сторінки (також у консолі: F12).

Рівень 4–6 балів

Завдання 1. Привітання

getFullName() + showGreeting()

Завдання 2. Оцінка студента

getStudentInfo(), checkGrade(), showResult()

Завдання 3. Чайові

calculateTip(amount, percent = 10) + showResult()

Рівень 7–9 балів

Завдання 1. Таймер із колбеком

startGreetingTimer(message, seconds, callback) — колбек є стрілковою функцією.

Завдання 2. Калькулятор

calculate(a, b, operation) + showResult()

Завдання 3. Лічильник кліків (замикання)

createClickCounter() — значення count запам’ятовується між викликами.

Рівень 10–12 балів

Завдання 1. Генератор випадкових чисел

function* randomGenerator(min, max) з нескінченним циклом.

—

Завдання 2. Генератор паролів

passwordGenerator() отримує символи через next(value); «done» завершує роботу.

Завдання 3. Генератор діалогів

chatBot() — yield повертає запит, відповідь передається через next(answer).

Завдання 4. Втрата контексту

Спочатку введіть ім’я. Кнопка «Say» використовує bind() і працює правильно, друга кнопка — присвоєння без bind() (this втрачається).
